## Goal

- Markdown-in-git storage for epics, stories and tickets
- Agent-friendly CLI with `--json` on every command

## Storage layout

```text
.sherpa/
├─ config.yaml          # project key, name
├─ epics/E-001.md       # frontmatter + markdown body
├─ stories/S-001.md     # parent: E-001
├─ tickets/T-0001.md    # parent: S-001
├─ sessions/*.jsonl     # append-only audit log, one file per session
└─ .local/              # gitignored: active ticket per session
```
