## Description

A one-shot `shp backfill` that upgrades tickets written before structured fields existed:

- `## Dependencies` → `depends` (the section is removed when it only listed keys)
- `## Acceptance criteria` → checks, ticked on done items that have a PR
- PR URLs from archived history → `links` (primary + related)
- `now` set from the latest log entry

It was trialled on a scratch copy, then applied to an imported project and to this repo (64 placeholders removed, T-0046's criteria became 4 checks).

Code: `internal/cli/backfill.go`.

## Why

S-014's checks, dependencies and PR links only help if older tickets carry them too. Otherwise the tree, Visuals and review cards are blank for most history. This ticket closes that gap once rather than by hand.

**Open for review:** no automated tests (one-shot migration). Spot-check a few backfilled tickets. Two imported tickets have no PR on record, and imported tickets still repeat a shared boilerplate section.
