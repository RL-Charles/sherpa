## Description

Show which tickets an agent is working on right now: a spinner replaces the ticket's status glyph in the tree and board, and the header names the agent. It starts when the agent starts a turn or touches the ticket, and stops when the agent's turn ends or it submits.

## Why

With several agents running, a human can't tell from the board which tickets are being worked on right now versus abandoned mid-way. A live spinner answers that at a glance and makes stalled work obvious. Part of S-006 (agent hooks): the heartbeat rides on the same hooks T-0044/T-0045 install. T-0060 extends it to the parent story and epic.

**Open for review:** existing repos must re-run `shp hooks install` to get the new heartbeat entries. The OpenCode `chat.message` heartbeat hasn't been tested against a real OpenCode, so check the spinner with Codex, Cursor and OpenCode.

## Acceptance criteria

- [ ] Hooks write a per-checkout heartbeat (new `working` event on prompt submit and every tool call)
- [ ] Stop hook and agent `shp submit` clear it; heartbeats older than 2 min are ignored
- [ ] Agent `shp start`/`log` tag the heartbeat with the ticket
- [ ] TUI animates only while someone is working (no idle redraws)
- [ ] Claude Code, Codex, Cursor and OpenCode installs emit the event
