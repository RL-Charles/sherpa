## Description

Idempotent install into .claude/settings.json, .cursor/hooks.json, Codex config and an OpenCode plugin; preserve existing settings; git commit-msg hook.

- `shp hooks install`: adds only Sherpa's entries and leaves the user's own hooks alone. Re-running it changes nothing.
- `shp hooks status`: shows which integrations are present.
- `shp hooks uninstall`: removes exactly what install added. Agent docs are left in place.

Code: `internal/hooks/install.go`, tests in `install_test.go`.

## Why

The adapters (T-0044) are useless if wiring them up means hand-editing four config formats. One command makes adopting Sherpa in a repo a single step and is safe to re-run after upgrades. T-0053 relies on this to deliver its new heartbeat hooks.
