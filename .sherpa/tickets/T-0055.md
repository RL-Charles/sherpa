## Description

The same program installs under two names:

- `shp`: the short name. Agents, hooks, scripts and docs keep using it.
- `sherpa`: the product name, for humans who'd rather type it.

`cmd/shp` and `cmd/sherpa` both call `cli.Execute`. Help text and errors use whichever name was invoked (`TestCommandName`). The README install section lists both.

## Why

`sherpa` is the discoverable name for people finding the project; `shp` is what every installed hook and agent prompt already calls. Shipping both under S-002 (Agent-friendly CLI) gives humans the friendly name without breaking any agent integration.
