## Description

Agent submissions land in a new `agent_review` status. A human or another agent reviews them there, then passes them on to human `review`, sends them back to in progress, or closes them as done (humans, or agents with `--approved-by`).

## Acceptance criteria

- [ ] New status agent_review (◒) between in_progress and review
- [ ] Agent `shp submit` → agent_review; human submit → review
- [ ] `shp review <id> --pass|--reject -m notes` records the verdict in the worklog
- [ ] Done from agent_review: humans, or agents with --approved-by
- [ ] TUI board section, picker option, `shp context` section, agent session context
