## Description

Two branches can both create `T-0031` and collide on merge.

| Option | Example | Collision-free | Readable | Verdict |
|---|---|---|---|---|
| Sequential (today) | `T-0031` | ✗ | ✓ | keep for solo |
| Sequential + suffix | `T-0031-k3` | ✓ | ~ | candidate |
| ULID | `T-01J9Z…` | ✓ | ✗ | no |
| Renumber on merge | `shp fix-ids` | ✓ | ✓ | candidate |

```text
branch A ──▶ new T-0031 ─┐
                         ├──▶ merge ──▶ shp audit flags duplicate ──▶ shp fix-ids
branch B ──▶ new T-0031 ─┘
```
