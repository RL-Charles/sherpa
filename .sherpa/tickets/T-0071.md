## Why

Sherpa's colours were xterm-256 picks that clashed with a Nord desktop and
agent TUI. Matching OpenCode's nord theme makes the TUI read as one family
with the tools beside it.

## Change

- `internal/palette`: the Nord palette (nord0–nord15, OpenCode's muted
  `#8B95A7`) and the roles the UI uses (primary, secondary, accent, muted,
  status hues, selection, borders), adaptive for light terminals.
- Every hard-coded colour in render, tui and worklog now names a role.
- Glamour markdown: Nord body text, headings, links, inline code, and the
  chroma `nord` theme for code blocks.
