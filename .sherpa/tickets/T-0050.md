## Description

When an agent opens a pull request, Sherpa links it to the ticket on its own — nobody copies URLs.

- **Hook capture:** the post-shell hook reads `gh pr create` output (Claude/Codex Bash, Cursor `afterShellExecution`, OpenCode bash) and stores the PR on the active ticket.
- **Submit warning:** `shp submit` looks up the branch's PR and warns when none is linked. It never blocks.
- **`shp sync`:** links PRs that already exist, matching by branch, title and ticket-key ranges.

Code: `internal/links/`, `internal/hooks/hooks.go`, `internal/cli/commands.go`.

## Why

Reviewers judge work by its PR. Without a link, a ticket shows a worklog but not the code change behind it. This is the data source for S-014's generated "Work done" block and the ⇡ marker in the tree (T-0051).

**Open for review:** capture has unit tests and a hand-audited sync (55 matches), but no live agent has created a real PR through the hook yet.
